# M2 md 변환 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `buildDoc`를 export해 고정 md 조각으로 DOM 단위 테스트를 붙이고, md 사이 링크·외부 링크·프롬프트 카드 복사를 e2e로 고정한다. 측정으로 찾은 버그 4개도 고친다.

**Architecture:** 변환은 지금처럼 `js/md.js` 한 파일에서 한다. 바뀌는 곳은 네 군데다.
- `md.js`: `buildDoc` export, 링크 규칙을 순수 함수 `rewriteHref`로 분리, 제목 id 충돌 처리, 코드 끝 줄바꿈 제거.
- `main.js`: 본문 안 링크로 이동하면 새 화면 제목에 초점을 둔다.
- 테스트: Playwright `dom` 프로젝트와 `tests/dom/`을 새로 만든다.

CSS·siteConfig는 바꾸지 않는다.

**Tech Stack:** 바닐라 ES 모듈, marked 18.1.1(`vendor/marked`), Node 22 `node:test`, `@playwright/test` 1.64.1(Chromium), `tests/serve.py`(8123).

**Spec:** [docs/specs/2026-11-08-guide-site-design.md](../specs/2026-11-08-guide-site-design.md) §3(`md.js`), §4(제목 데이터·링크 규칙), §5(복사 실패), §6(단위·DOM·e2e), §8 M2. 기준: [brief](../brief.md) '가이드 읽기'·'md 사이 링크', [GLOSSARY.md](../../GLOSSARY.md).

- 최종 워크플로우 변환 결과: 표 9(카드형 7), 체크 목록 7(체크박스 26), 경고 2, 배지 17(전부 `measure`), 프롬프트 카드 40, 글자 그림 1, 통과 조건 상자 7. 디자인 스킬 가이드에 `guess` 배지 1. `search` 배지는 md 3개 어디에도 없다.
- 제목: 화면 h1~h4 수가 코드 블록 밖 md 제목 수와 같다(final 21, steps 54, design 16). id 중복 0. h5·h6은 없다.
- 외부 링크 3개(design)는 `target="_blank"`가 붙는다. final 5행의 다른 가이드 링크 2개는 `#/steps`·`#/design`으로 바뀐다.
- **버그 1 (복사 끝 줄바꿈)**: 첫 프롬프트 카드 [복사] → 클립보드 `"/plugin install superpowers@claude-plugins-official\r\n"`. md 원문 끝에는 줄바꿈이 없다.

- **버그 4 (제목 id 충돌)**: `a`, `a`, `a-1` 제목이면 id가 `a`, `a-1`, `a-1`로 겹친다. 기준 출처: marked PR #1401이 인용한 github-slugger 테스트는 겹치면 접미사를 더 붙인다(`a-1-1`).

## Global Constraints

- md 원문 문장은 바꾸지 않는다. 모양만 바꾼다. 배지가 괄호를 모양으로 바꾸는 것은 기존 결정이다.
- 색·글꼴·간격은 `css/tokens.css` 토큰만 쓴다. 이번 마일스톤은 CSS를 바꾸지 않는다. 바꿔야 하면 DESIGN.md부터 고친다.
- 사이트 이름·URL·가이드 목록·UI 문구는 `js/site-config.js`에서만 가져온다. 테스트도 문구를 하드코딩하지 않고 `siteConfig.ui`를 쓴다.
- 공용 컴포넌트를 재사용한다: md 변환 `js/md.js`, 아이콘 `icon()`, 초점 `focusEl`(`js/scroll.js`). 같은 역할을 새로 만들지 않는다.
- 배포본은 빌드·npm 의존성이 없다. 새 devDependency도 없다. marked는 `vendor/` 그대로.
- 모션은 `transform`·`opacity`만, `prefers-reduced-motion`이면 즉시 표시. 이번 작업은 모션을 건드리지 않는다.
- UI 문구는 합니다체. 새 문구를 만들지 않는다(`ui.copy`·`copied`·`copyFailed`·`newTab`·`warning`을 쓴다).
- 브랜치는 `m2-md-render`(`main` 기준). 원격 푸시, PR, `main` 합치기는 사용자 확인을 받는다.
- **사소한 문제도 미루지 않는다**(사용자 결정, 2026-11-09). 리뷰 Minor도 이 마일스톤 안에서 RED→GREEN으로 고친다. executing-plans의 'Minor는 ledger로 미룸'보다 우선한다.

## Review Focus

1. **복사한 프롬프트가 원문과 다름**(끝 줄바꿈, 배지·경고 모양이 섞임): 붙여 넣은 글이 md 코드 블록과 글자 하나까지 같아야 한다. → Task 2 `code blocks keep text exact`, Task 4 `copy puts the exact md code block on the clipboard`
2. **본문 링크로 다른 가이드 이동 뒤 초점**: 키보드 사용자는 새 가이드 제목에서 이어 읽어야 한다. → Task 3 `md link to another guide opens it and focuses its title`
3. **다른 가이드의 특정 제목을 가리키는 링크**(`파일.md#제목-id`): 그 가이드의 그 제목으로 가야 한다. → Task 3 단위 `guide link with fragment keeps the heading id`
4. **같은 이름 제목이 여러 번, 또는 `-1`로 끝나는 제목**: id가 겹치지 않아 목차·단계 주소가 엉뚱한 곳으로 가지 않아야 한다. → Task 1 `heading ids never collide`
5. **클립보드가 막힌 브라우저**: '복사 못 함'이 보이고 화면 낭독기에도 알려야 한다. → Task 4 `copy failure shows the failed label`

### Task 3: md 사이 링크·외부 링크 (완료 기준 3)

**Files:**
- Create: `tests/dom/links.spec.mjs`, `tests/e2e/md-render.spec.mjs`
- Modify: `tests/unit/md.test.mjs`(Task 1에서 만든 파일에 덧붙임)
- Modify: `js/md.js`(`rewriteHref` export, `markLinks`가 사용), `js/main.js`(본문 링크 초점)

**Interfaces:**
- Consumes: `render` (Task 1), `parse` from `js/router.js`, `focusEl` from `js/scroll.js`
- Produces: `export function rewriteHref(href: string, guide: Guide) → { href: string, external: boolean }` in `js/md.js`. DOM을 쓰지 않는다. 규칙:
  1. `^https?://`(대소문자 무시) → `{ href, external: true }`
  2. `#조각`만 있음 → `#/<guide.id>/<디코드한 조각>`
  3. 경로의 마지막 조각(디코드, `#` 앞)이 어떤 가이드의 `legacyNames`와 같음 → `#/<그 가이드 id>` + 조각이 있으면 `/<디코드한 조각>`
  4. 그 밖(`mailto:`, 다른 상대 경로) → 그대로, `external: false`
  - 디코드 실패(`%E0%A4%A`)는 원문으로 비교한다(예외 없음).

- [ ] **Step 1: 실패하는 단위 테스트** `tests/unit/md.test.mjs`에 덧붙인다(import 줄은 합친다)
