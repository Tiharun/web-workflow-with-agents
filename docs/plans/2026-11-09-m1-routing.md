# M1 라우팅·상태 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 주소 해석을 `js/router.js` 순수 함수로 분리하고, 없는 주소·없는 단계·md 불러오기 실패가 처음 들어올 때와 화면 안에서 바뀔 때 모두 같게 처리되도록 고친다. 그리고 JS 없이 보이는 정적 문구가 siteConfig와 같다는 것을 테스트로 고정한다.

**Architecture:** 화면 모듈과 공용 컴포넌트는 M0 그대로 쓴다(`.state`·`.notice`·`.btn`·`icon()`). 이번에 바뀌는 곳은 다섯 군데다.
- `main.js`: 주소 해석을 `router.parse`로 넘긴다.
- `guide.js`: 처음 그릴 때와 단계만 바뀔 때 둘 다 `scrollToStage` 한 함수를 거친다.
- `main.js`·`guide.js`: 성공 표시(`data-loaded`)와 `onRetry`로 오류 상태를 라우터와 맞춘다.
- `site-config.js`: 정적 문구 6개를 더한다.

CSS는 바꾸지 않는다.

**Tech Stack:** 바닐라 ES 모듈, Node 22 `node:test`, `@playwright/test` 1.64.1(Chromium), `tests/serve.py`(8123).

**Spec:** [docs/specs/2026-11-08-guide-site-design.md](../specs/2026-11-08-guide-site-design.md) §3(`router.js`), §5(없는 단계·md 실패), §6, §8 M1. 기준: [brief](../brief.md), [DESIGN.md](../../DESIGN.md), [GLOSSARY.md](../../GLOSSARY.md).

## 측정한 출발점 (2026-11-09, Chromium, 동작 줄이기)

- **없는 단계**: `#/final/없는단계`에 바로 들어갈 때와 가이드 안에서 해시만 바꿀 때 모두 안내 1개, `scrollY` 0, 안내가 본문 첫 요소로 같게 나온다. 다른 점은 초점이다. 앞 단계 제목에 있던 키보드 초점이 화면 밖에 그대로 남는다.
- **버그 1**: md 실패 화면에서 같은 가이드의 단계 주소로 바꾸면, 오류 상자 위에 '찾는 단계가 없어…' 안내가 붙는다. 다시 받지도 않는다.
  - 원인: `main.js`의 같은 가이드 판정이 `.doc:not([aria-busy])`라서, 오류 상태도 '그려짐'으로 본다.
- **버그 2**: [다시 시도]로 연 가이드를 떠나 홈에서 스크롤하면, 진행 막대가 `scaleX(1)`로 남는다.
  - 원인: 다시 시도가 `renderGuide`를 직접 불러서, 정리 함수가 라우터에 전달되지 않는다.

## Global Constraints

- 색·글꼴·간격·모서리·그림자는 `css/tokens.css` 토큰만 쓴다. 이번 마일스톤은 CSS를 바꾸지 않는다. 바꿔야 하면 DESIGN.md부터 고친다.
- 공용 컴포넌트를 재사용한다: 상태 화면 `.state`, 안내 `.notice`, 버튼 `.btn`, 아이콘 `icon()`. 같은 역할을 새로 만들지 않는다.
- 사이트 이름·URL·저장소 주소·가이드 목록·UI 문구는 `js/site-config.js`에서만 관리한다. 예외는 JS 없이 보여야 하는 정적 문자열(`index.html`의 `<title>`·description·noscript·건너뛰기 문구, `404.html` 전체)뿐이고, 이 값은 e2e가 siteConfig와 같은지 검사한다.
- md 원문 문장은 바꾸지 않는다.
- 모션은 `transform`·`opacity`만 쓰고, `prefers-reduced-motion`이면 즉시 표시한다.
- UI 문구는 합니다체로 쓴다. 새 문구는 만들지 않는다. 기존 HTML의 문장을 그대로 siteConfig로 옮긴다.
- 배포본은 빌드·npm 의존성이 없다. 새 devDependency도 없다.
- 브랜치는 `m1-routing`이다. 원격 푸시, PR 만들기, `main`에 합치기는 사용자 확인을 받는다.

```js
const final = guideById('final');

  assert.deepEqual(parse('#/final/a/b'), guide('a/b'));

test('broken percent-encoding does not throw', () => {
  assert.deepEqual(parse('#/final/%E0%A4%A'), guide('%E0%A4%A'));
```

```js
const finalFile = guides.find((g) => g.id === 'final').file;
async function blockFinal(page) {
  const ctl = { blocked: true, requests: 0 };
  await page.route(`**/${finalFile}`, (r) => { ctl.requests++; return ctl.blocked ? r.abort() : r.continue(); });
  return ctl;
}

test('blocked md shows the error; retry renders the body with a new request', async ({ page }) => {
  const ctl = await blockFinal(page);
  await page.goto('/#/final');
  const alert = page.getByRole('alert');
  await expect(alert.locator('h1')).toHaveText(ui.loadError);
  const src = alert.getByRole('link');
  await expect(src).toHaveAttribute('href', `${site.repoUrl}/blob/${site.branch}/${finalFile}`);
  await expect(src).toHaveAttribute('target', '_blank');
  ctl.blocked = false;
  await alert.getByRole('button', { name: ui.retry }).click();
  await expect(page.locator('#doc h1')).toHaveText(finalH1);
  await expect(page.getByRole('alert')).toHaveCount(0);
  expect(ctl.requests).toBeGreaterThanOrEqual(2);
});

test('changing stage while the error is shown retries instead of a notice', async ({ page }) => {
  const ctl = await blockFinal(page);
  await page.goto('/#/final');
  await expect(page.getByRole('alert')).toBeVisible();
  ctl.blocked = false;
  await page.evaluate(() => { location.hash = '#/final/0단계-준비'; });
  await expect(page.locator('[id="0단계-준비"]')).toBeInViewport();
  await expect(page.locator('.notice')).toHaveCount(0);
  await expect(page.getByRole('alert')).toHaveCount(0);
});

test('leaving a retried guide stops progress tracking', async ({ page }) => {
  const ctl = await blockFinal(page);
  await page.goto('/#/final');
  await expect(page.getByRole('alert')).toBeVisible();
  ctl.blocked = false;
  await page.getByRole('button', { name: ui.retry }).click();
  await expect(page.locator('#doc h1')).toHaveText(finalH1);
  await page.evaluate(() => { location.hash = '#/'; });
  await expect(page.locator('html')).toHaveAttribute('data-view', 'home');
  await page.evaluate(() => scrollTo(0, document.documentElement.scrollHeight));
  await expect(page.locator('.progress__bar')).toHaveAttribute('style', /scaleX\(0\)/);
});
```
