# 프레임워크 없이 바닐라 JS, 라이브러리는 저장소에 직접 포함

React·Vite 같은 프레임워크와 빌드 단계 없이 HTML·CSS·JS(ES 모듈)로 만든다(초보자가 빌드 없이 운영). 라이브러리(marked, GSAP, 필요 시 three)는 CDN 대신 `vendor/`에 버전을 고정해 넣는다. CDN이 내려가면 md를 그리지 못해 글이 사라지기 때문이다. DOMPurify는 넣지 않는다: 읽는 md는 같은 저장소의 직접 쓴 파일뿐이다.

## Consequences

- 외부 md나 사용자 입력을 읽게 되면 DOMPurify 도입을 다시 판단해야 한다.
- 라이브러리 버전은 출시 2주 이상 지난 안정판으로 고정하고, 갱신은 직접 교체한다.
