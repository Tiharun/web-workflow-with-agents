# 가이드 글은 md 원본을 브라우저에서 읽어 그린다

가이드 3개의 글은 HTML에 넣지 않고, 페이지가 열릴 때 `content/`의 md 원본을 불러와 화면에 그린다. md만 고치면 사이트가 바뀌어 원본이 한 곳에만 있게 하려는 선택이다. 비주얼은 md 제목에 붙는 별도 층이며, 제목이 바뀌어 짝을 못 찾으면 그 비주얼만 숨기고 글은 그대로 보인다.

## Considered Options

- md 내용을 HTML에 직접 넣기: 파일 하나로 끝나지만 md와 HTML을 따로 고쳐야 해 원본이 둘이 된다.
- 배포 때 md를 HTML로 미리 만들기(GitHub Actions): JS 없이도 글이 보이지만 빌드 과정이 생겨 초보자 운영 부담이 커진다.

## Consequences

- JS가 꺼지거나 스크립트가 실패하면 가이드 글이 보이지 않는다. 의도된 예외다. JS가 꺼지면 안내 문구와 md 원본 3개 링크를 보여 주고, 불러오기 실패 시 오류 안내·다시 시도·원본 링크를 보여 준다.
- `file://`로 열면 md 불러오기가 막히므로 로컬 확인과 QA는 로컬 서버(`http://localhost`)로 한다.
